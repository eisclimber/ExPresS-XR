# Archery Minigames (BaAM)

A collection of archery based game mechanics created by Lena Matulla.

Grab a bow, pull the string, aim and release your grip to shoot!

## Features

- Bow Interactables with physical arrows and a functional bowstring.
- Pythicial targets reacting to bow hits
- A hit-based scoring system
- Good and bad targets with target randomization
- Target Thrower, spawning targets with an impulse
- Target Line, spawning targets and moving them along a line
- An Exhibition about japanese bow culture 


## Setup

- Create a bow or use an existing one.
- Create and configure targets.
- Create a GameObject with a Arrow Game Logic and Score Manager
- Configure the scoring, which targets are considered in the game and other things.
- Have fun!
